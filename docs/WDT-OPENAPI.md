# 旺店通开放平台 API 接入清单

> 目标：每天自动拉订单 / 库存进本系统，替代手工导出。
> 前提：**appkey/appsecret 只能由企业主账号在开放平台申请**，任何脚本都拿不到。
> 客户端里没有、也不该有这组凭据（已在本机安装目录与本地库确认过）。

## 一、申请（你来做，约 10 分钟 + 审核）

1. 打开 **https://open.wangdian.cn** ，用**客户端登录的那个主账号**（子账号没有权限）。
2. 进「**自助对接**」→ 创建应用：
   - 应用名称：`振颜丽舍数据同步`
   - 用途：财务系统每日取订单/库存/商品数据
   - 勾选接口权限：仓库、库存、订单、商品（按实际需要）
3. 提交审核 → 应用上线 → 做「内部授权」。
4. 在「正式授权管理」里抄三个值：

| 值 | 含义 | 来源 |
| --- | --- | --- |
| `sid` | 卖家账号 | 购买 ERP 时分配，或授权管理页可见 |
| `appkey` | 接口账号 | 应用详情 |
| `appsecret` | 接口密钥 | 应用详情（点查看） |

> 测试阶段可用 `sandbox.wangdian.cn`，正式环境是 `api.wangdian.cn`。

## 二、填进项目

`.env` 追加（**不要提交仓库、不要发群**）：

```ini
WDT_SID=
WDT_APPKEY=
WDT_APPSECRET=
```

验证：

```bash
npm run wdt:check          # 调 warehouse_query.php，能返回仓库列表就说明通了
npm run wdt:check -- --sandbox   # 走测试环境
```

签名算法已按官方示例校验通过（`npm run wdt:test` → PASS）。

## 三、⚠️ 一个必须先知道的限制

官方文档写明：**标准 API 不返回淘系（天猫/淘宝）及系统供销平台订单**，要拿全平台订单得接「奇门自定义接口」（另需资质与联调）。

所以：

| 渠道 | 标准 API | 备注 |
| --- | --- | --- |
| 京东 / 拼多多 / 自有商城 | ✅ 可拿 | 先跑这条 |
| 淘宝 / 天猫 | ❌ 拿不到 | 需奇门接口，或继续用渠道日报导入 |
| 库存 / 仓库 / 商品 | ✅ 可拿 | 不受影响 |

如果天猫占比高，建议：**库存与京东/拼多多走 API，天猫继续走日报导入**，两条并存最省事。

## 四、IP 白名单

标准 API 靠 `sign` 鉴权，本次查到的官方文档**没有提到强制 IP 白名单**。申请时留意页面是否有「IP 白名单」必填项：

- 没有 → 家宽直接调，IP 变了也不影响。
- 有且必填 → 再考虑最小云服务器中转（几十元/年）。

## 五、拿到 key 之后我做什么

1. `--check` 验证连通与权限；
2. 写 `tools/wdt-sync.mjs`：按天增量拉订单/库存，落到 `sales_daily` 与库存表，按业务单号去重；
3. 挂每日定时（与企微备份同样的方式），失败留痕、不静默；
4. 与现有销售看板、损益口径对齐（收入/退款/成本/平台费分别取哪张表，写进 `rules/finance-pnl-rules.md`）。
