# 企微 AIBot 应答与归属规则（A 方案）

> 适用：员工通过企业微信 AIBot 与本机助理对话。通道**不透传 userid**，所以归属靠「署名 + 文件名」。
> 规则版本：2026-11-19 · 配合 `tools/aibot-sync.mjs` 使用。

## 一、归属判定优先级（同步器已实现）

1. **正文署名**：`张三：查下这个月的表` 或 `[张三] 查下…` —— 最高优先
2. **附件文件名里的姓名** —— 次优先
3. **两者都没有** → 记为「企微成员」，进入公共会话，**不允许猜**

## 二、文件名规范（建议全员统一）

推荐格式：

```
姓名-YYYY-MM-DD-内容.xlsx
例：张三-2026-11-19-天猫日报.xlsx
```

兼容以下写法（同步器都能识别）：

| 写法 | 示例 | 识别结果 |
| --- | --- | --- |
| 姓名在前 | `张三-2026-11-19-天猫日报.xlsx` | 张三 |
| 姓名在前（下划线） | `张三_京东明细.csv` | 张三 |
| 姓名在后 | `天猫日报-李四.xlsx` | 李四 |
| 括号 | `天猫日报（王五）.xlsx` | 王五 |
| 无姓名 | `汇总表.xlsx` | 未归属 |

> 识别时会排除「天猫 / 京东 / 日报 / 明细 / 报表 / 汇总 / 订单」等业务词与纯数字，避免把渠道名当成人名。

## 三、会话组织（自动）

| 情况 | 会话 ID | 标题 |
| --- | --- | --- |
| 识别到姓名 | `wecom-aibot-<姓名>-YYYYMMDD` | 企微助理 · 张三 · 11-19 |
| 未识别 | `wecom-aibot-YYYYMMDD` | 企微助理 · 11-19 |

- 助手回复**跟随提问所在会话**，并在正文前加 `↳ 回「原问题摘要」`，保证问答成对、顺序不乱
- 纯文字消息默认进公共会话，**不做人物归属**（符合"文字消息不必记录是谁"）

## 四、回复长度要求

| 消息类型 | 要求 |
| --- | --- |
| 纯文字提问 | **简短回答**：结论 1–2 句，不铺开、不重复问题 |
| 带附件的报表 | 先给**结论一行 + 3–5 个关键数字**（销售额 / 退款 / 净利 / 净利率），不复制整表 |
| 需要长回答 | 回「已整理，稍后给文件」，再输出 Excel/CSV |
| 无法识别归属 | 不要猜姓名；如需确认，只问一句「请问是哪位？」 |

## 五、禁止事项

- ❌ 把甲的报表算到乙名下
- ❌ 文件名里没有姓名时，凭印象猜测发送人
- ❌ 纯文字消息也去建"某某"的会话
- ❌ 在群里指名道姓复述别人上传的数据

## 六、验收

1. 张三发 `张三-2026-11-19-天猫日报.xlsx` → 会话「企微助理 · 张三 · 11-19」，附件入台账 `sender_name=张三`
2. 李四发同格式文件 → 独立会话，互不串
3. 发 `汇总表.xlsx`（无姓名）→ 进公共会话，标记「企微成员」
4. 发纯文字「今天大盘怎么样」→ 公共会话，回复 ≤ 2 句
