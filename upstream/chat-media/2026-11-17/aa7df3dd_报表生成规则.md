## 2. 工作表结构与表头

### 2.1 总月报表（汇总多主体）
- 标题行：第 1 行 `A1:O1` 合并，内容 `总月对比表`，居中。
- 第 2 行分组表头（合并）：
  - `A2:A<末尾-小计>` 合并为第一列主体名
  - `C2:D2`=销售数量，`E2:F2`=销售额，`G2:H2`=退货，`I2:J2`=退货金额
- 第 3 行明细表头：
  | 列 | A | B | C | D | E | F | G | H | I | J | K | L | M | N | O |
  |---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
  | 含义 | 主体 | 月份 | 销售数量 | 增长比 | 销售额 | 增长比 | 退货数量 | 增长比 | 退货金额 | 增长比 | 毛利润 | 毛利率 | 销售净利额 | 销售净利率 | 总结 |
- 每个主体区块：11 行（1月～11月）+ 1 行 `小计`；最后一行 `总计`。

### 2.2 主体月对比表（每个主体一张）
- 标题：`A1:N1` 合并，内容 `<主体>月对比表`。
- 分组表头：`B2:C2`=销售数量，`D2:E2`=销售额，`F2:G2`=退货，`H2:I2`=退货金额。
- 第 3 行：`B`销售数量 `C`增长比 `D`销售额 `E`增长比 `F`退货数量 `G`增长比 `H`退货金额 `I`增长比 `J`毛利润 `K`毛利率 `L`销售净利额 `M`销售净利率 `N`总结。
- A 列 = 月份（1月～11月）。

### 2.3 日汇总表（当月）
- 标题：`A1:M1` 合并，`日汇总表`。
- 第 2 行按“日”合并分组（每天 4 列：`B2:E2`=1日、`F2:I2`=2日 …）。
- 第 3 行每组固定 4 个指标：`销售数量 / 销售额 / 费比 / 毛利率`。
- A 列行主体：渠道（天猫 / 抖音 / 小红书 / 京东 / 分销 + `总计`）。

### 2.4 主打单品分析各渠道（当月）
- 标题：`A1:S1` 合并。
- 第 2 行按“日”合并，每天 3 列（销售数量 / 销售额 / 毛利率）。
- A 列 = 主打品/增长品名称，末行 `总计`。

## 3. 计算口径

- 增长比 = (本月 − 上月) / 上月；首月留空；上月为 0 时留空。
- 毛利率 = 毛利润 / 净销售额。
- 销售净利率 = 销售净利额 / 净销售额。
- 费比 = 平台费用 / 销售额。
- 净销售额 = 销售额 − 退货金额。

## 4. 数据映射约定

- 标准样例按「品牌」分主体（歌剧 / PF / 世家）。
- 若数据源无品牌维度，则按**渠道**分主体（如 天猫 / 京东 / 拼多多），并在 `总结` 列注明映射口径。
- 数据源缺 SKU/数量维度时，对应表保留表头骨架，数值留空并注明，**不得删表、不得改表头**。

## 5. 执行检查清单（每次生成后自检）

1. 字体是否宋体 11、细边框、无填充？
2. 合并区域是否与样例一致（标题、分组表头、主体列）？
3. 列顺序与表头文字是否逐字一致？
4. 增长比 / 毛利率 / 净利率 / 费比是否按第 3 节口径？
5. 是否保留全部工作表（缺数据也要留骨架）？
