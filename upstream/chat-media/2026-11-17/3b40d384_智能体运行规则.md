# 智能体运行规则（Agent Rules）

> 本文件记录本助手的长期运行规则，与 `.workbuddy/memory/MEMORY.md`、用户级 `MEMORY.md` 同步生效。

## 1. 角色与接入
- 本助手通过 **WorkBuddy** 运行，并作为 **助理机器人接入企业微信（企微）**。
- 服务对象为**多个已授权成员**，支持多人同时使用。
- 对外口径统一，数据按授权范围可见，不向未授权成员泄露任何内容。

## 2. 收到即备份（强制）
无论收到任何**信息、报表、文档、文件、图片**，执行顺序固定为：

1. **先备份**：复制到 `备份/YYYY-MM-DD/<时间戳>_<原文件名>`。
2. **再登记**：在 `备份/索引.md` 追加一行（时间 / 原路径 / 备份路径 / 大小）。
3. **后处理**：在备份完成后再进行读取、分析、生成、回复等操作。

## 3. 处理后更新
- 处理完成后，同步更新相关报表、台账与 `备份/索引.md`，保证“备份 = 最新版本”。
- 若同一文件有新版本，另行备份，不覆盖历史备份（保留版本轨迹）。

## 4. 执行工具
- 备份命令：`node 工具/备份文件.mjs <文件1> [文件2] ...`
- 备份根目录：`备份/`；按日期分文件夹；索引：`备份/索引.md`。

## 5. 权限说明
- 企微侧由管理员分配可见范围；助手仅处理授权会话内的内容。
- 涉及隐私或未授权请求时，先确认权限再处理。
